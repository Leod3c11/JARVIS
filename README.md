# JARVIS — Local Android Assistant

Repositório inicial do JARVIS. Projeto Android Kotlin + Jetpack Compose, preparado para receber IA local, voz offline, memória e integração segura com Android.

> Core 0.1 é apenas a fundação: ainda não contém um LLM integrado e não executa comandos root.

Consulte `docs/ROADMAP.md` e `docs/SECURITY.md`.
